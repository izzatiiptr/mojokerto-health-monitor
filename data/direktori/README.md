# Template direktori

`fasilitas.csv` disediakan dengan kolom:
`Nama_Fasilitas, Jenis_Fasilitas, Kecamatan, Alamat, Latitude, Longitude, Google_Maps_URL, Sumber_Verifikasi`.

Jangan membuat koordinat perkiraan. Isi lokasi setelah pemeriksaan sumber dan Google Maps.
Jika belum memiliki data lokasi valid, halaman Peta & Direktori menampilkan pemberitahuan.
