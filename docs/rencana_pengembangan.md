# Tahapan pengembangan

1. **Fondasi repository:** struktur kode, data historis, data analisis, dan aplikasi multipage (sudah disiapkan).
2. **Audit data:** cocokkan seluruh indikator dan definisi dengan notebook final Project 1; simpan bukti rekonsiliasi puskesmas 2023.
3. **Desain UI:** review desain 2.5D, responsivitas seluler, konsistensi filter dan grafik.
4. **Direktori fasilitas:** verifikasi alamat, kecamatan, koordinat dan tautan Google Maps untuk 6 puskesmas dan 6 RS sebelum pengisian CSV.
5. **Kualitas udara:** uji kegagalan API, waktu pembaruan, kategori dan interpretasi US AQI.
6. **Pengujian:** validasi unit data, pengujian fungsi dan navigasi, kemudian *deployment* GitHub → Streamlit Community Cloud dan evaluasi.

**Catatan:** repositori ini adalah proyek akademik, bukan aplikasi resmi Diskominfo atau Dinkes Kota Mojokerto.
